# Changelog — FIFA World Cup 2026 Analytics Dashboard

## [1.1.0] — 2026-08-05
### Added
- Breadcrumb drill-down navigation (Tournament -> Continent -> Team -> Player)
- Global filters sidebar (stage, team, continent, position, venue, referee, elevation)
- Methodology transparency module (all custom metrics expose formula, variables, weighting, normalization, assumptions, limitations)
- Advanced match metrics: Chance Creation, Finishing Efficiency, Defensive Efficiency, GK Efficiency, Match Momentum, Playing Style, Aggressiveness Index
- Team radar charts (vs tournament average) and rolling trends
- Player comparisons: vs Player, vs Team Average, vs Position Average, vs Tournament Average
- Estimated air pressure and oxygen availability from elevation (ISA standard atmosphere)
- Climate classification by elevation
- Correlation analysis: environment vs match metrics

### Changed
- All 8 pages updated with breadcrumb navigation, global filters, and methodology annotation
- Team analysis: attack, defense, discipline, rolling trends, radar, team vs team/continent/tournament
- Player analysis: 4 comparison tabs, position breakdown, team-scoped player selector
- Environmental analysis: pressure/oxygen estimates, climate classification, correlation scatterplots
- Match Explorer: 4 advanced metric tabs (chance creation, finishing, defensive, momentum)
- Documentation: milestones 1-14 marked complete
